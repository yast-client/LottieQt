# LottieQt

LottieQt allows you to integrate Lottie, as well as TGS (Telegram Stickers, GZipped lottie) animations in Qt/QML applications easily. Besides a Qt image plugin, which allows lottie files to be used in e.g. QML `AnimatedImage` objects, it also includes a more complex `LottieItem` object, which supports several other features, which cannot be added to AnimatedImage, such as setting scaled size.
